# /cardnews

서비스 소개 카드뉴스 한 세트를 만든다. 기본 순서는 문제 → 해결 → 사전신청 안내 3장이다. 사용자가 다른 구성이나 장수를 말하면 그대로 따른다.

## 저장 규칙 (중요)

- 결과는 항상 새 폴더 `outputs/cardnews-N/`에 저장한다. N은 기존 `outputs/cardnews-*` 중 가장 큰 번호 + 1이다. (`cardnews-1`이 있으면 `cardnews-2`)
- 기존 카드 폴더는 수정·삭제·덮어쓰기 하지 않는다. `render.js`는 이미 있는 폴더에는 쓰지 않고 오류로 멈춘다.
- 사용자가 "방금 세트를 고쳐 줘"라고 하면 그 세트를 고치지 말고 새 번호 폴더에 수정본을 만들고, 어떤 폴더가 이전본인지 알려 준다.

## 순서

1. `CLAUDE.md`, `brand/brand.json`, `outputs/idea-brief.md`를 읽는다. 이름, 슬로건, 고객, 문제, 해결 방법, 핵심 기능은 여기서 가져온다.
2. 카드에 필요한 정보 중 문서에 없는 것(사전신청 방법, 혜택, 마감일, 계정 등)은 사용자에게 하나씩 묻는다. 질문마다 보기 3개를 주고, 고르거나 직접 쓰게 한다. 사용자가 정하지 않은 것은 지어내지 않는다. 할인율, 마감일, 가격처럼 확정되지 않은 값은 카드에는 "예정"으로만 쓰거나 빼고, `caption.md`의 "확인 필요"에 적는다.
3. 카드 문구를 정리해 `spec.json`을 만든다. 형식과 예시는 `example-spec.json`을 보라.
   - 카드마다 `label`, `title`, 그리고 `body`, `items`(목록), `button` 중 필요한 것, 하단 `foot`.
   - 마지막 카드는 자동으로 파란 배경(CTA 테마)이 된다.
   - 제목은 두 줄 이내, 본문은 두 문장 이내로 짧게 쓴다. 1장은 문제, 2장은 해결과 핵심 기능, 3장은 사전신청과 슬로건 순이다.
4. 스펙 파일은 프로젝트 폴더 밖(scratchpad)에 두고 실행한다.
   ```
   node .claude/skills/cardnews/render.js <spec.json>
   ```
   출력 폴더를 생략하면 다음 번호 폴더에 저장한다. 실행 후 출력된 폴더 경로를 사용자에게 알린다. "내용이 1080px를 넘칩니다" 경고가 나오면 글을 줄이고, 방금 이번 실행이 만든 미완성 폴더만 지운 뒤 다시 실행한다. 이전 세트 폴더는 지우지 않는다.
5. 만든 PNG를 모두 직접 열어 글자가 잘리거나 서로 붙지 않았는지, 글꼴이 브랜드 글꼴로 나왔는지 확인한다. 문제가 있으면 글을 줄이거나 `render.js`의 간격을 조정한다.
6. 같은 폴더에 `caption.md`(인스타 게시 문구)를 쓴다. 구성: 본문(문제 → 해결 → 사전신청 안내), 해시태그 8개 안팎, 확인 필요 체크리스트. 카드와 같은 사실만 쓴다.
7. 프로젝트 규칙에 따라 `log.md`에 날짜·요청·결과를 한 줄 추가하고, 한국어 커밋 메시지로 커밋·푸시한다.

## 디자인 기준 (`render.js`에 반영됨)

- 1080×1080 PNG, 좌우 여백 96px, 왼쪽 정렬.
- 글자는 크게 쓴다: 제목 104px, 본문과 목록 54px, 라벨 42px, 하단 문구 38px. 작은 글자로 되돌리지 않는다.
- 로고는 모든 카드 상단에 크게 넣는다(128px, 이름 80px). 로고를 빼거나 줄이지 않는다.
- 색, 글꼴, 로고는 `brand/brand.json`과 `brand/logo.svg`. 제목은 Noto Serif KR 700, 본문은 IBM Plex Sans KR. 글꼴은 Google Fonts에서 불러오므로 네트워크가 막히면 대체 글꼴로 나온다. 이 경우 사용자에게 알린다.
- 상단에 로고와 이름, 오른쪽에 `n / 총장수`, 하단에 한 줄 문구.
- 글자가 커졌으므로 제목은 두 줄 이내, 본문은 한 문장(두 줄 이내)으로 쓴다. 3장처럼 본문과 버튼이 함께 있으면 본문을 한 줄로 줄인다. 내용이 넘치면 `render.js`가 "넘칩니다" 경고를 낸다.

## 필요한 것

- Node와 playwright(`/opt/node22/lib/node_modules/playwright`), Chromium(`/opt/pw-browsers/chromium`). 경로가 다르면 `CHROMIUM_PATH` 환경 변수를 쓴다.
