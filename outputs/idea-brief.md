# 아이디어 브리프

> 한 줄 아이디어: 밍글링투어처럼 2030을 타겟으로 한 소셜링 투어 (낯선 사람들과 함께 떠나며 친해지는 여행)

| 항목 | 내용 |
|------|------|
| 고객 | 혼자 여행 가고 싶은 20대 중후반 |
| 불편한 상황 | 혼자 가면 어색하고 외롭다 |
| 우리 해결 방법 | 성향 매칭 + 자유 동행 투어 (여행 스타일·성향으로 팩을 짜 주고, 일정은 느슨하게) |
| 핵심 기능 1 | 신원·후기 인증 |
| 핵심 기능 2 | 안심 귀가 체크 |
| 핵심 기능 3 | 재만남 매칭 |
| 돈 버는 방법 | 투어 참가비 수수료 (참가비의 15~20%를 플랫폼 수수료로) |

## 한 줄 요약
혼자 떠나고 싶지만 어색하고 외로운 20대 중후반을, 성향이 맞는 사람들과 안심하고 어울리게 해 주고 참가비 수수료로 돈을 번다.
