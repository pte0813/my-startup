# 데이터 모델 (Supabase / Postgres)

## 테이블

### areas (동네)
| 컬럼 | 타입 | 설명 |
|------|------|------|
| slug | text PK | `seongsu` 같은 영문 식별자 |
| name | text | 성수, 연남, 이태원·한남 … |
| sort_order | int | 칩 정렬 |

### profiles (사용자)
| 컬럼 | 타입 | 설명 |
|------|------|------|
| id | uuid PK | `auth.users.id` 참조 |
| display_name | text | 표시 이름 |
| role | enum(`member`,`editor`,`admin`) | 기본 `member` |
| created_at | timestamptz | |

### places (가게)
| 컬럼 | 타입 | 설명 |
|------|------|------|
| id | uuid PK | |
| area_slug | text FK → areas | |
| name | text | 같은 동네 안에서 유일 |
| category | text | 우동, 파스타 … |
| situations | text[] | `데이트`, `혼밥`, `팀 회식` 중 |
| summary | text | 한 줄 소개 |
| wait_tip | text null | 웨이팅 팁(웹 검색 기준 또는 에디터 작성) |
| reservation_tip | text null | 예약 요령 |
| address | text null | |
| photo_path | text null | Storage 경로 |
| status | enum(`published`,`draft`,`closed`) | 기본 `published` |
| sort_order | int | 목록 정렬 |
| created_by | uuid null | 에디터 |
| created_at, updated_at | timestamptz | |

> 지도 좌표(`lat`,`lng`)는 이번 범위에 넣지 않는다. 프로토타입의 좌표는 임의 배치였으므로 가져오지 않는다. 지도 연동 때 실제 좌표를 추가한다.

### reviews (후기)
| 컬럼 | 타입 | 설명 |
|------|------|------|
| id | uuid PK | |
| place_id | uuid FK → places | |
| author_id | uuid FK → profiles | 에디터 |
| rating | int | 1~5 |
| visited_on | date | 오늘 이전 |
| wait_minutes | int null | 0~600 |
| body | text | 한 줄 후기, 2~200자 |
| tip | text null | 예약·웨이팅 팁, 200자 이하 |
| sponsored | boolean | 협찬·초대 방문 여부 |
| created_at | timestamptz | |

### saves (찜)
| 컬럼 | 타입 | 설명 |
|------|------|------|
| user_id | uuid FK → profiles | |
| place_id | uuid FK → places | |
| created_at | timestamptz | PK는 (user_id, place_id) |

## 파생 값 (뷰 `place_stats`)
- `review_count`, `avg_rating`, `last_visited_on`(= 마지막 검증일), `has_sponsored`.
- "검증 N일 전"은 화면에서 `last_visited_on`과 오늘을 비교해 계산한다(90일 초과 시 경고).

## 접근 규칙 (RLS)
| 테이블 | 읽기 | 쓰기 |
|--------|------|------|
| areas | 모두 | 관리자 |
| places | 모두(`published`만), 에디터·관리자는 전체 | 에디터·관리자 |
| reviews | 모두 | 에디터는 본인 것만 추가·수정·삭제, 관리자는 전체 삭제 |
| profiles | 본인 + 관리자(표시 이름은 후기 표시용으로 공개 뷰 제공) | 본인(표시 이름만), 관리자(역할) |
| saves | 본인 | 본인 |
| Storage `place-photos` | 모두 | 에디터·관리자 |

## 초기 데이터
- 프로토타입의 14개 동네 201곳을 `supabase/seed/places.json`으로 옮겨 `published`, 검증 전(후기 없음)으로 넣는다.
- 가게 정보는 2026년 10월 웹 검색 기준이며, 직접 방문 검증 전이다.
