# 몽몽 서비스 개요

## 한 줄 소개
웨이팅 팁과 예약 요령까지, 직접 다녀온 사람이 검증한 동네 맛집 큐레이션 앱.

## 해결하려는 문제
- 맛집 정보는 많지만 **가기 전에 꼭 필요한 정보**(언제 가야 덜 기다리는지, 어떻게 예약하는지)는 흩어져 있다.
- 협찬 후기와 낡은 정보가 섞여 있어 "실패하지 않는 선택"을 하기 어렵다.

## 대상 사용자
- 서울 주요 동네(성수, 연남, 홍대, 강남 등)를 자주 가는 2030.
- 상황별(데이트, 혼밥, 팀 회식)로 빠르게 고르고 싶은 사람.

## 차별점
1. **웨이팅·예약 팁이 카드 첫 화면에 보인다.** 열어 보지 않아도 가기 전 핵심을 안다.
2. **직접 다녀온 기록으로 검증한다.** 후기는 에디터만 쓰고, 마지막 검증일을 보여 준다.
3. **오래된 정보를 숨기지 않는다.** 검증 후 90일이 지나면 경고를 붙인다.
4. **협찬을 반드시 표기한다.** 신뢰가 서비스의 핵심 자산이다.

## 이번 단계(MVP 이후 첫 제품)의 범위
- 포함: 동네·상황별 목록, 검색, 가게 상세(웨이팅·예약·후기), 에디터 후기·가게 관리, 찜, 로그인, 사진 업로드.
- 제외(보류): 지도 연동(외부 지도 링크만 제공), 결제·예약 대행, 일반 사용자 후기 작성, 소셜 로그인, 알림.

## 수익화 아이디어 (제품 범위 밖, 참고)
- 심화판 유료 판매, 가게 제휴, 예약 대행 수수료(법적 범위 확인 필요).

## 핵심 위험
| 위험 | 대응 |
|------|------|
| 정보가 낡는다 | 검증일 표시, 90일 경과 경고, 업데이트 주기 정하기 |
| 협찬으로 신뢰가 깨진다 | 협찬·초대 방문 체크를 필수 입력으로 두고 카드에 표기 |
| 외부 정보를 그대로 가져와 저작권 문제가 생긴다 | 사진은 직접 찍거나 허락받은 것만 쓴다. 외부 리뷰는 링크로만 연결한다 |
| 검색으로 모은 초기 데이터가 부정확하다 | 모든 가게를 "검증 전"으로 시작해 에디터가 방문 후 갱신한다 |
