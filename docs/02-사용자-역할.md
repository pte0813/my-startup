# 사용자 역할과 권한

| 역할 | 누구 | 할 수 있는 일 |
|------|------|---------------|
| 방문자 | 로그인하지 않은 사용자 | 가게 목록·검색·상세·후기 조회 |
| 회원 | 로그인한 일반 사용자 | 방문자 권한 + 가게 찜, 내 찜 목록 |
| 에디터 | 직접 다녀오는 큐레이터 | 회원 권한 + 가게 추가·수정, 후기 작성·수정·삭제(본인 것), 사진 등록 |
| 관리자 | 서비스 운영자 | 에디터 권한 + 모든 후기 삭제, 역할 부여, 가게 비공개·폐업 처리 |

## 원칙
- 후기는 에디터만 쓴다(핵심 가치인 "직접 다녀온 검증"을 지키기 위해).
- 권한은 화면에서만 숨기지 않고 **DB의 행 수준 보안(RLS)으로 강제**한다.
- 역할은 `profiles.role`에 저장하고, 관리자만 바꿀 수 있다.
- 첫 관리자는 DB에서 직접 지정한다(배포 절차에 포함).

## 로그인
- 1차: 이메일 로그인(Supabase Auth, 매직링크). 비밀번호 관리는 하지 않는다.
- 이후: 카카오·구글 로그인 추가(각 서비스의 앱 등록이 필요하다).
