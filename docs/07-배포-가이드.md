# 배포 가이드 (Vercel + Supabase)

계정을 만들고 화면에서 설정하는 일은 사람이 한다. 순서를 지키면 된다. 서비스 롤 키는 앱이 쓰지 않으므로 어디에도 입력하지 않는다.

## 1. Supabase 준비
1. supabase.com 에서 가입하고 **New project**를 만든다(리전은 Seoul 권장, DB 비밀번호는 따로 보관).
2. 왼쪽 **SQL Editor**에서 `supabase/migrations/20261020000000_init.sql` 내용을 붙여 넣고 실행한다(테이블·RLS·사진 저장소가 만들어진다).
3. 같은 방식으로 `supabase/seed.sql`을 실행한다(동네 22개, 가게 461곳). 이미 이전 버전을 올렸더라도 다시 실행하면 새 동네·가게만 추가되고 기존 데이터는 그대로다(여러 번 실행해도 안전).
4. **Project Settings > API**에서 `Project URL`과 `anon public` 키를 복사해 둔다.

## 2. GitHub 저장소 확인
- 배포할 브랜치(예: `main`)에 이 저장소의 코드가 올라가 있어야 한다. 작업 브랜치만 있으면 PR을 만들어 합친다.

## 3. Vercel 프로젝트 만들기
1. vercel.com 에서 GitHub 계정으로 가입 → **Add New > Project** → 이 저장소를 Import.
2. **Root Directory**를 `apps/web`으로 지정한다(Framework는 Next.js로 자동 인식).
3. 모노레포이므로 **Include source files outside of the Root Directory**를 켠 채로 둔다(`packages/shared`를 쓰기 때문).
4. **Environment Variables**에 입력한다(Production·Preview 모두).

| 이름 | 값 |
|------|----|
| `NEXT_PUBLIC_SUPABASE_URL` | 1-4의 Project URL |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | 1-4의 anon public 키 |
| `NEXT_PUBLIC_SITE_URL` | 배포 주소(예: `https://mongmong.vercel.app`). 첫 배포 뒤 주소를 알면 넣고 다시 배포한다 |

5. **Deploy**를 누른다. 빌드가 끝나면 `https://<프로젝트>.vercel.app`이 열린다.

## 4. Supabase에 배포 주소 알리기
**Authentication > URL Configuration**
- **Site URL**: 배포 주소.
- **Redirect URLs**: `https://<배포 주소>/auth/callback` 추가(로컬 시험용으로 `http://localhost:3000/auth/callback`도 가능).
- 이 단계를 빼먹으면 로그인 메일 링크가 동작하지 않는다.

## 5. 첫 관리자 지정
1. 배포된 사이트의 `/login`에서 본인 이메일로 로그인 링크를 받아 로그인한다(프로필이 자동 생성된다).
2. Supabase **SQL Editor**에서 실행한다(이메일을 바꿔서).
```sql
update public.profiles set role = 'admin'
where id = (select id from auth.users where email = '내이메일@example.com');
```
3. 이후 다른 에디터는 관리자 권한으로 `set_user_role` 로 지정한다.

## 6. 배포 후 확인 (처음 한 번)
- 로그인 메일이 오고 링크로 로그인된다.
- 에디터 계정으로 후기 저장, 가게 사진 업로드, 찜이 된다.
- 회원(에디터가 아닌) 계정은 후기·가게 화면에서 막힌다.
- 휴대폰 브라우저에서 "홈 화면에 추가"가 된다(HTTPS 필요, Vercel은 기본 제공).
- 문제가 있으면 Vercel **Deployments > Logs**와 Supabase **Logs**를 본다.

## 7. 이후 운영
- `main`에 푸시하면 자동 배포되고, PR마다 미리보기 주소가 생긴다.
- 가게 데이터는 관리자 화면(`/admin/places/new`)에서 고친다. `seed.sql`은 처음 한 번만 쓴다.
- 도메인 연결: Vercel **Settings > Domains**에서 추가하고 안내된 DNS를 설정한 뒤 `NEXT_PUBLIC_SITE_URL`과 Supabase Site URL을 새 주소로 바꾼다.
- Supabase 무료 플랜은 일정 기간 미사용 시 일시 정지될 수 있다. 운영을 시작하면 플랜을 확인한다.
