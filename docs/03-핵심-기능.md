# 핵심 기능

우선순위: **P0** = 첫 배포에 필수, **P1** = 첫 배포 직후, **P2** = 이후.

## 탐색
| 기능 | 설명 | 우선순위 |
|------|------|----------|
| 동네 선택 | 22개 동네를 칩으로 고르고 동네별 가게 수를 보여 준다 | P0 |
| 내 주변 | 현재 위치에서 가까운 동네 3곳을 거리와 함께 보여 준다. 위치는 기기 안에서 동네 중심 좌표와의 거리만 계산하고 서버로 보내거나 저장하지 않는다. 가게 단위 거리는 좌표 데이터가 생긴 뒤에 추가한다 | P1 |
| 상황 필터 | 전체·데이트·혼밥·팀 회식 | P0 |
| 가게 카드 | 썸네일, 이름, 동네·종류, 평점·후기 수, 최근 후기 또는 웨이팅 요약, 검증 상태 | P0 |
| 검색 | 가게·종류·동네·소개 문구 검색, 추천 검색어 | P0 |
| 홈 | 후기 높은 맛집, 웨이팅 팁이 있는 맛집, 동네 둘러보기 | P0 |

## 가게 상세
| 기능 | 설명 | 우선순위 |
|------|------|----------|
| 가기 전에 | 웨이팅 팁, 예약 요령, 검증일 또는 "웹 검색 기준" 안내 | P0 |
| 찾아가기 | 주소, 네이버 지도·카카오맵·구글 지도·다이닝코드·캐치테이블 검색 링크 | P0 |
| 다녀온 뒤 | 후기 목록(별점, 방문일, 실제 대기 시간, 한 줄, 예약·웨이팅 팁, 협찬 표기) | P0 |
| 이전·다음 가게 | 목록으로 돌아가지 않고 이어서 둘러보기 | P1 |
| 사진 | 가게 대표 사진(에디터 업로드), 없으면 종류 타일 | P0 |

## 에디터 도구
| 기능 | 설명 | 우선순위 |
|------|------|----------|
| 후기 작성 | 별점, 방문일, 대기 시간, 한 줄 후기, 팁, 협찬 여부. 저장하면 검증일이 갱신된다 | P0 |
| 가게 추가·수정 | 동네, 종류, 이름, 상황, 소개, 웨이팅·예약 팁, 주소 | P0 |
| 사진 등록 | 이미지를 줄여서 저장소에 올린다 | P0 |
| 후기 삭제 | 본인 후기 삭제(관리자는 전체) | P0 |

## 회원
| 기능 | 설명 | 우선순위 |
|------|------|----------|
| 로그인 | 이메일 매직링크 | P0 |
| 찜 | 가게를 저장하고 마이에서 본다 | P1 |

## 신뢰 장치 (모든 화면에 적용)
- 후기가 없는 가게는 "검증 전"으로 표시한다.
- 마지막 검증 후 90일이 지나면 "검증 N일 전" 경고를 붙인다.
- 협찬·초대로 방문한 후기는 "협찬" 표기를 붙이고 가게 카드에도 알린다.
- 정보 출처와 한계를 안내 화면에 적는다.

## 보류
- 지도 연동(외부 지도 링크로 대체), 일반 사용자 후기, 알림, 결제·예약 대행, 소셜 로그인, 운영 통계.
