1. **기획 문서화** — 이 폴더의 문서 (완료)
2. **기술 스택·CLAUDE.md** — Next.js + TypeScript + Tailwind + Supabase (완료)
3. **뼈대** — 모노레포, 앱 초기화, DB 스키마·RLS, 공통 레이아웃, 시드 데이터 (완료)

6. **검증** — 브라우저 확인, 보안 점검(RLS·입력 검증), 코드 리뷰
