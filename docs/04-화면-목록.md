# 화면 목록

## 구조
- 하단 탭: **홈 · 검색 · 리스트 · 마이** (지도 탭은 지도 연동 때 추가). 가게 상세와 관리 화면에서는 탭을 숨긴다.
- 상단: 로고(몽몽 캐릭터), 안내 버튼, 밝기 전환 버튼

## 화면
| 화면 | 경로 | 내용 | 접근 |
|------|------|------|------|
| 홈 | `/` | 오늘의 추천 문구, 바로가기, 후기 높은 맛집, 웨이팅 팁이 있는 맛집, 동네 둘러보기 | 모두 |
| 검색 | `/search` | 검색창, 추천 검색어, 결과 카드 | 모두 |
| 리스트 | `/list` | 동네 칩, 상황 칩, 가게 카드 목록 (`?area=성수&situation=데이트`) | 모두 |
| 가게 상세 | `/places/[id]` | 가기 전에 / 찾아가기 / 다녀온 뒤, 이전·다음 가게 | 모두 |
| 후기 쓰기 | `/places/[id]/review/new` | 별점·방문일·대기 시간·한 줄·팁·협찬 여부. 입력 오류는 입력값을 유지한 채 안내 | 에디터 |
| 가게 추가·수정 | `/admin/places/new`, `/admin/places/[id]/edit` | 가게 폼, 대표 사진 등록·삭제(수정 화면) | 에디터 |
| 로그인 | `/login`, `/auth/callback` | 이메일 입력 → 링크 발송 → 링크를 누르면 돌아와 로그인 | 모두 |
| 마이 | `/me` | 계정·역할, 내 찜, (에디터) 내 후기·가게 추가, 로그아웃 | 회원 |
| 안내 | `/about` | 데이터 출처와 한계, 협찬 표기 정책 | 모두 |

## 사용자 여정
1. 홈에서 동네를 고른다. → 2. 리스트에서 상황을 고른다. → 3. 카드에서 웨이팅 요약을 본다.
4. 상세에서 예약 요령과 후기를 확인하고 지도 링크로 위치를 본다. → 5. 다녀온 뒤 에디터는 후기를 남긴다.

## 상태 화면
- 불러오는 중, 결과 없음, 오류, 권한 없음, 로그인 필요를 모든 목록·폼에 정의한다.
